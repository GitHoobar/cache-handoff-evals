# Two legal tool arguments

This follow-up was specified after inspecting free generations on the Qwen 3 14B → Ministral 3 14B route. Both arms wrapped every JSON action on that route in a Markdown fence. Some first-turn parser and behavior diagnostics were already available. The following grammar, six directions, two panels and 48 cases were fixed before running any constrained action.

For each case, expose exactly the two declared editable symbols through the tool grammar. Serialize each possible action as compact JSON with a single `symbol` string field. Tokenize each complete string alone using the receiver tokenizer with special-token insertion disabled. Require exact decoding back to the JSON, different paths and no stop token in either sequence. Use these two specific tokenizations. The grammar enforces JSON validity and membership in the declared two-symbol enum.

In the token trie, every token is forced until the two strings first diverge. Condition the receiver on the same repository prefix and question tokens as its free generation, plus those shared forced tokens. At the sole branch, choose the higher model logit of the two allowed next tokens. Equal logits choose the smaller token ID. All remaining tokens on that branch are forced, then the action terminates at its leaf. This is native or translated greedy selection under a finite grammar. Full answer likelihood and reference labels play no part in selecting a branch.

Record the two candidates and token IDs, shared prefix, branch logits, signed margin in manifest choice order, chosen action, cumulative input length, original free-record hash, and input-token hashes. On the first case per route and arm, verify the unrestricted vocabulary argmax against the released HF greedy engine at the same branch context. Apply the same fixture dispatcher and behavior tests to every selected action. Summarize panels separately and examine each counterbalanced pair. Performance here describes a tool with exactly two legal strings, which removes invalid calls and exposes the allowable argument names. The free-generation experiment remains a separate measurement.
