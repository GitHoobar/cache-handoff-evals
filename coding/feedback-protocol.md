# Coding handoff with a test-and-retry loop

This extension was specified before coding predictions were available. On all 24 archive-plus-current cases for Qwen 3 14B → Ministral 3 14B and the reverse, run the native and translated policies through the same edit tool. End the task when a single dispatched edit passes both the requested and preserved behavior checks. Otherwise discard the edit, show the tool's schema error or the failing behavioral tests, and let the same receiver make one more edit from the initial working tree. Never reveal the correct constant name or alternative candidate in the diagnostic. Save and score the second action, including invalid responses. The retry policy consumes model-dependent feedback, so its final outcome measures the whole two-attempt policy. Report first-pass and final outcomes, eligibility, recoveries and remaining failures.

Scope is two admissible constants in an original repository per task. A failed test can make the choice easier by elimination. The archive comparison combines extra length, past context and an obsolete mapping. The experiment uses native prefill and the released translator inside the same toy tool loop. It measures completed edits to fixtures and the behavior of their tests.
