# When a cache handoff changes the record a tool retrieves

One unchanged SQuAD passage asks which country was relatively unaffected by the oil embargo. Each of seven models identified the UK when reading the document. With cache translation, 30 of the 42 ordered sender–receiver handoffs retained the UK. Five answered Norway, five Switzerland and two Sweden. The model outputs, decoder settings, gold answers and token IDs are in [the raw archive](all-models/matrix-results.tar.gz). [Figure](handoff-answers.png) · [All 49 paths including native controls](handoff-matrix.png)

We used Ramp and Base Labs’ released BF16 translator. The receiving model still has the document through the translator’s ordinary text interface. Source and target are frozen. We used greedy decoding with a 24-token cap. All 42 translated answers on this question stopped naturally. The full evaluation included 64 questions across 48 articles, scored over the same 42 directions. Relative to each receiver reading the text directly, translation lost 141 normalized exact matches and gained 136. The embargo case was selected after inspecting results. The 42 directions on this question share the passage and model set. [Original research](https://labs.baseten.co/articles/speculative-encoding-many-to-many-cache-translation) · [Model pins](all-models/models.json)

The replay reads the actual free-text answers. A fixed parser maps the four countries to record IDs, then retrieves records from an in-memory table. All 42 translated answers resolved to a record, including 12 that identified the wrong country. The seven native answers all retrieved the UK. The parser and registry were constructed for this example. This illustrates the limitation of checking whether an argument is a valid record key. Production routing, real tool calls generated by a model and software changes would require separate experiments. [Every lookup](lookup-results.json)

## Reproduce the counts

Run from the extracted bundle directory. The numeric checks use only the Python standard library.

```sh
python3 replay_lookup.py all-models/matrix-results.tar.gz --output replayed.json
cmp replayed.json lookup-results.json
python3 all-models/audit_failures.py > audited.json
cmp audited.json all-models/failure-audit.json
```

To regenerate the opening image, install matplotlib and run `python3 plot_handoff.py all-models/matrix-results.tar.gz handoff-answers.png`. The model results are saved generations. The replay does not invoke model inference.
